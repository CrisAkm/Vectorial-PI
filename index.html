01 · Definición de Algoritmo
Una secuencia finita de pasos ordenados diseñada para resolver un problema específico.

Cada paso es preciso y no ambiguo: dada una entrada, el algoritmo garantiza llegar a una salida en un número finito de operaciones.

02 · Definición de Estructura de Datos
La organización lógica y física de la información dentro de la memoria de una computadora.

No basta con guardar datos: la forma en que se organizan determina qué tan rápido podemos trabajar con ellos.

Permite búsqueda eficiente
Permite inserción eficiente
Permite eliminación eficiente
03 · Algoritmo + Estructura de Datos
Algoritmos + Estructuras de Datos = Programas — Fórmula de Niklaus Wirth, 1976

La eficiencia de un programa no depende solo del algoritmo, ni solo de la estructura: depende de elegir la combinación correcta para el problema que se está resolviendo.

04 · Definiciones Clave

Cuatro conceptos que conectan todo lo demás

→ Algoritmo

Procedimiento paso a paso que transforma entradas en salidas de forma determinista.

→ Estructura de datos

La forma de organizar la información en memoria para operar sobre ella eficientemente.

→ Tipos de dato

La naturaleza de los valores que se manipulan: numéricos, textuales, lógicos.

→ Notación Big O

Notación matemática para medir la eficiencia de un algoritmo según su entrada.
